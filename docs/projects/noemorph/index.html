AI Research Skill

Noemorph.

把一个研究问题拓展成可追溯的研究路径。

从问题、假设或观察出发，跨学科寻找可迁移的解释，再选出值得深挖的方向。每一轮留下的发现、来源和未决问题，都能在知识地图里继续追踪。

体验项目 GitHub 仓库

交互知识地图

原项目的示例图谱。可以拖动地图、缩放、筛选、搜索，也可以点开节点查看分支和来源。

独立打开

使用方式

展开初始问题
从多个角度改变观察对象、过程或抽象层次，找到原来问题框架之外的研究方向。
选择路径深入
分轮调查候选方向，把证据、假设与待验证的问题一起记录，未选中的分支也可回看。
回到交互式地图
在浏览器里搜索、筛选和展开分支，沿地图回溯来源，或导出 HTML、JSON 和 SVG。

作为 Agent Skill 安装到支持的 AI 客户端，由客户端提供模型与检索能力。仓库包含可本地打开的示例地图。
