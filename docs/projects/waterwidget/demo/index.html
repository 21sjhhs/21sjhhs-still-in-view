水量怎样算出来

把杯子视为绕中心轴旋转的立体。每一层的截面积是 πr(t)²，把有水的各层积分，再除以满杯的积分，就得到体积比例。

V(h) = C × ∫1−h1 πr(t)² dt∫01 πr(t)² dt

C 是满杯容量，h 是从杯底量起的水位比例。t 从杯口 0 到杯底 1，r(t) 由当前杯型决定。程序用 180 段梯形积分近似计算。
